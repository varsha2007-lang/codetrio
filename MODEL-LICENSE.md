# Model license and attribution

The default model name is `Qwen/Qwen2.5-3B-Instruct`, an open-weight instruction model released under Apache License 2.0 by the Qwen team. Model weights are not bundled with this project. Review the model card and its license/acceptable-use terms at the source repository before downloading or deploying it. Changing `MODEL_NAME` may select a model with different terms; users/operators are responsible for compliance. PayGuard AI's source-code license is separate (see LICENSE).
